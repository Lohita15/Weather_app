# 🌦️ Weather Forecast App

A modern and interactive weather forecasting application built with **Streamlit** and **WeatherAPI**. The app provides real-time weather information, 3-day forecasts, hourly forecasts, weather alerts, favorite cities, historical weather data, and interactive visualizations.

> This project demonstrates API integration, interactive dashboards, and data visualization using Python and Streamlit.

---

## ✨ Features

- 🌍 Search weather by city
- 🌡️ Real-time weather conditions
- 📅 3-Day weather forecast
- ⏰ 24-hour hourly forecast
- ❤️ Save and manage favorite cities
- ⚠️ Weather alerts
- 📈 Interactive weather charts
- 📆 Historical weather lookup
- 🎵 Dynamic background music
- 🎥 Animated weather background
- 📱 Responsive Streamlit interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/weather-app.git
```

### Navigate into the project

```bash
cd weather-app
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Create a `.env` file

```env
WEATHER_API_KEY=your_weatherapi_key
```

### Run the application

```bash
streamlit run app.py
```

The application will open automatically in your browser.

---

## 📖 How It Works

1. Enter the name of a city.
2. The application sends a request to WeatherAPI.
3. Current weather information is retrieved.
4. Forecast and historical weather data are displayed.
5. Interactive charts and weather media enhance the user experience.
